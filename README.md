# Speakai

SpeakAI is an AI-powered English speaking learning website designed to help users practice their speaking skills through interactive tasks and gamification.

## Features

* Voice-based speaking practice
* AI-powered speaking evaluation
* Speaking scores and feedback
* XP, coins, levels, and badges
* Interactive missions and quests
* User authentication and profile
* Learning progress tracking

## Tech Stack

* React.js
* Vite
* Tailwind CSS
* Node.js
* Express.js
* Firebase / Firestore
* OpenAI GPT-4o
* Web Speech API
